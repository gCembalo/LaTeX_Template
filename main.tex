% I created this template to write notes, handouts, summaries, and actually
% even my thesis (after adjusting the cover page) in LaTeX. 
% The template is organized as follows: inside the "Chapter" folder you 
% should place all .tex files containing the body of the document; 
% inside the "Figure" folder you should obviously place all the figures used 
% in the document. If the document is particularly long,
% I recommend organizing the figures into subfolders named after the 
% corresponding .tex file; in the "Diagram" folder there are the code for
% figure created with the package tikzpicture, i.e. Feynman diagrams. 
% See the command \diagram in "NotesTemplate.sty" to see how it works.
% It's covenient separate the figure from tikzpicture from the document
% because they are preatty heavy, and it can be affect the compilation
% time. The file "Bibliography.bib" is clearly the bibliography of the
% document (I use biblatex). The last important file is 
% "NotesTemplate.sty", which can be seen as the complete list of 
% packages (organized by theme) and commands that I usually use, or that are
% generally useful for writing a scientific document.

% In 0-Preface.tex file there is, obviously, the document's preface. You
% don't need to modify it, it containg just the essential information
% and it's automatically filled by the standard setting that you give
% in this document (main).

% Note that inside the "Chapter" folder there is also "Title page", which
% of course contains the code for the title page. I organized the main.tex
% in a way that you can never fell the necessity to open that file.
% Anyway, this folder also contains an image, so you need to upload yours
% in the folder, and put its path in the following command \poster. 

% The template is organized so that you write the various chapters separately 
% and then include them in the main file using the command \input{...}, 
% after the already included introduction chapter
% (\include{Chapter/1-Introduction}).

% When you decide to use this template, you need to know which parts to
% modify before starting to write your text:
% 
% main.tex : all the information in "SETTING" section
% Bibliography.bib : your reference texts
% Title page folder : Figure
